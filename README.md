# IMDB-Redesign
Creating the home page of Juxtopposed's redesign of IMDb, using HTML and CSS. 

I wanted to solidify my understand of the various tools available to me in HTML and CSS. Creating a professional and clean looking website was challenging but I had the redesign template to help me out. I also added a lot of interactivity, the cursor changes upon hovering over buttons, titles, movie posters and much more. Also the various elements on the webpage react smoothly and dynamically to your actions. At the end, this was a fun project and I hope to improve it in the future.
